# My React Native App

This project is a React Native application that demonstrates a simple splash screen followed by a home screen. 

## Features

- **Splash Screen**: Displays a logo and a loading indicator while the app is initializing.
- **Home Screen**: The main content of the app is displayed after the splash screen.

## File Structure

```
my-react-native-app
├── src
│   ├── components
│   │   └── SplashScreen.tsx
│   ├── screens
│   │   └── HomeScreen.tsx
│   ├── App.tsx
│   └── types
│       └── index.ts
├── package.json
├── tsconfig.json
└── README.md
```

## Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd my-react-native-app
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Running the App

To run the application, use the following command:
```
npm start
```

Follow the instructions in the terminal to run the app on your desired platform (iOS or Android).
